## Objetivo
Esse projeto tem o objetivo de fazer a movimentação do robô até as caixas e verificar qual caixa é a mais leve, ou seja, a certa.

## Passo a passo de elaboração
- **1ºPASSO:** Configura motores, sensores, leds.
- **2ºPASSO:** Posicionamento de caixas
- **3ºPASSO:** Lendo sensores de proximidade e posição das caixas
- **4ºPASSO:** Agora vem os passo a passo para identificar as caixas
  - **4.1ºPASSO:** Se o sensor frontal identificar algo
  - **4.2ºPASSO:** Empurra a caixa
  - **4.3ºPASSO:** Lê as posições das caixas e verifica se alguma se moveu
  - **4.4ºPASSO:** Se ele não achou a caixa certa gira no próprio eixo para mudar a direção
  - **4.5ºPASSO:** anda e gira procurando
  - **4.6ºPASSO:** se achar a caixa leve gira no próprio eixo comemorando
